# Re-Tooth Dental Clinic Website

## About the Project

Re-Tooth is a dental clinic website developed to provide information about the dental practice and allow patients to interact with its online booking system.

The website includes patient accounts, appointment booking and a separate dashboard for staff to manage appointments.

## Features

- Homepage with information about the dental practice.
- Information about dental services.
- Patient registration and login.
- Patient dashboard.
- Online appointment requests.
- Staff dashboard for managing appointments.
- Patient records and appointment reports.
- Privacy policy page.

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- Git and GitHub

## Running the Project Locally

1. Clone the repository from GitHub:
   git clone https://github.com/BAphane3/dentalPracticeWebsite.git

2. Open the downloaded project folder in Visual Studio Code.

3. Open the `index.html` file.

4. Use the Live Server extension in Visual Studio Code to run the website in your browser.

## Database

Supabase is used for the website's authentication and database functionality. It manages patient accounts, profiles and appointment information.
